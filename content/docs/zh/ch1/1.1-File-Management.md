## 一、Windows 文件系统

### 1.1.1 盘符与目录树

Windows 用字母表示磁盘分区，最常见的是 `C:`（系统盘）和 `D:`、`E:` 等数据盘。每个盘下面是一棵目录树，目录用反斜杠 `\` 分隔：

```text
C:\
├── Windows\              # Windows 系统文件目录
├── Program Files\        # 64 位软件默认安装位置
├── Program Files (x86)\  # 32 位软件默认安装位置
├── Users\
│   └── 你的用户名\       # 用户目录
└── ProgramData\          # 程序共享数据
```

> [!INFO] 盘符与分区的关系
>   
> `C:` 一定是系统盘，但 `D:` 不一定是第二块硬盘——它可能只是同一块硬盘上的另一个分区。新电脑建议至少分两个区，把系统和数据分开存放。
>
> 关于分区：
> 不建议分超过两个区，除非你的磁盘空间足够大，对于总容量 ≤ 2TB 的硬盘，分两个区（系统盘与数据盘）已然足够。过多分区会导致空间利用率低，且管理麻烦。

### 1.1.2 用户目录

打开"此电脑"，双击你的用户名，进入用户目录。它包含几个系统预设的子目录：

| 文件夹 | 用途 |
| :--- | :--- |
| `桌面` | 临时放正在处理的文件与各类程序的快捷方式 |
| `文档` | 存放文档、笔记、聊天记录默认位置 |
| `下载` | 浏览器下载的默认位置 |
| `图片` | 截图、图片素材 |
| `音乐`、`视频` | 媒体文件 |

> [!CAUTION]
> 桌面本质上是 `C:\Users\你的用户名\Desktop` 这个文件夹，它在系统盘里。一旦系统崩溃需要重装，桌面文件很容易丢失。重要文件请放到数据盘，创建相应文件夹的快捷方式。

**验证当前用户目录路径：**

```powershell
echo %USERPROFILE%   # 输出当前用户目录，例如 C:\Users\SSJ
```

### 1.1.3 路径：绝对路径与相对路径

**绝对路径**是从盘符开始的完整地址，能在任何地方精确定位一个文件：

```text
C:\Users\SSJ\Documents\CS\数据结构\笔记.md
```

**相对路径**是从当前位置出发的地址。假设你在 `CS` 文件夹里，想引用 `数据结构` 文件夹里的 `笔记.md`，只需写：

```text
数据结构\笔记.md
```

> [!TIP] 两个特殊符号
> `.` 表示当前目录，`..` 表示上一级目录。例如从 `数据结构` 引用 `算法` 文件夹里的内容，写作 `..\算法\模板.md`。这两个符号在命令行和代码里极其常用。

## 二、文件命名规范

### 1.2.1 命名原则

好的文件名应该做到"看名知意"，避免出现 `新建文件夹`、`未命名`、`final final v2` 这类名称。建议遵循以下原则：

| 原则 | 说明 | 示例 |
| :--- | :--- | :--- |
| 见名知意 | 名字能反映文件内容 | `2024秋-数据结构-实验报告1.md` |
| 避免特殊字符 | 不用 `\ / : * ? " < > \|` | 这些字符在 Windows 中有特殊含义 |
| 慎用空格和中文 | 命令行里需要额外加引号 | 英文文件名用连字符或下划线分隔 |
| 版本管理用数字 | 用 `v1`、`v2` 或日期 | 不要堆"最终版""真的最终版" |

> [!WARNING] 禁用字符清单
> Windows 文件名中 **绝对不能** 出现这些字符：`\ / : * ? " < > |`。包含它们会导致重命名失败或文件无法打开。空格虽然合法，但在命令行和编程中容易引发问题，建议用 `-` 或 `_` 替代。

### 1.2.2 推荐命名模板

不同场景套用不同模板，直接照抄即可：

```text
# 课程资料
{学年}-{学期}-{课程名}-{资料类型}.{扩展名}
示例: 2024秋-数据结构-课件.pdf

# 实验报告
{课程名}-实验{编号}-{你的姓名}.{扩展名}
示例: 数据结构-实验3-张三.docx

# 项目代码（全小写英文，连字符或下划线分隔）
示例: student-management-system
```

> [!NOTE] 为什么代码项目要用英文命名
> 很多开发工具对中文路径支持不完善，路径越短在终端里切换越方便。代码项目建议放在 `D:\Projects\my-first-app`，而不是 `C:\Users\张三\桌面\我的文件\新建文件夹\my first app`。

## 三、文件夹组织方法

### 1.3.1 按用途分层

建议按"学年 → 学期 → 课程 → 类型"的层级组织学习资料，顺着清晰路径就能快速定位：

> [!DETAILS-EXAMPLE] 按学年分层的目录结构
> 以下示例展示如何按"学年 → 学期 → 课程 → 类型"组织 `Documents` 目录：
>
> ```text
> Documents\
> ├── CS\                          # 计算机相关资料根目录
> │   ├── 2024秋\
> │   │   ├── 数据结构\
> │   │   │   ├── 课件\
> │   │   │   ├── 作业\
> │   │   │   ├── 实验报告\
> │   │   │   └── 笔记\
> │   │   ├── 高等数学\
> │   │   └── 英语\
> │   └── 2025春\
> │       ├── 操作系统\
> │       └── 计算机网络\
> ├── Projects\                    # 个人项目
> │   ├── 个人博客\
> │   └── 算法练习\
> └── Archive\                     # 归档，放不再活跃但需保留的内容
>     └── 2023秋\
> ```

**验证目录结构：**

- [ ] 在资源管理器地址栏输入你的根目录路径，能看到清晰的分层结构即说明组织得当

### 1.3.2 区分工作区与归档区

每学期结束后，把上一学期的资料整体移到 `Archive` 文件夹里。这样工作区永远只放当前正在用的东西，不会越积越多。

> [!TIP] 归档时机
> 每学期开学前花 10 分钟做一次归档：新建本学期的文件夹结构，把上学期内容移入 `Archive`。这个习惯能让你的工作区常年保持清爽。

### 1.3.3 代码项目单独管理

代码项目建议放在专门的 `Projects` 或 `Code` 文件夹下，路径尽量短、全英文、无空格。

```text
# 推荐的代码存放路径
D:\Projects\my-first-app

# 不推荐的路径
C:\Users\张三\桌面\我的文件\新建文件夹\my first app
```

## 四、文件扩展名与类型

### 1.4.1 显示扩展名

Windows 默认隐藏已知文件扩展名，这会带来两个麻烦：一是无法快速判断文件类型，二是容易给恶意程序可乘之机（例如把 `病毒.exe` 伪装成 `报告.pdf.exe`，隐藏扩展名后看起来就是 `报告.pdf`）。

#### 方法一：资源管理器设置

打开任意文件夹 → 顶部菜单 `查看` → 勾选 `文件扩展名`（Windows 11 为 `查看` → `显示` → `文件扩展名`）。

#### 方法二：文件夹选项

`Win + R` → 输入 `control folders` → 切换到 `查看` 标签 → 取消勾选"隐藏已知文件类型的扩展名"。

> [!IMPORTANT] 必须开启扩展名显示
> 扩展名显示是防范伪装病毒的第一道防线。看到 `报告.pdf.exe` 这类双扩展名文件，基本可以判定为恶意程序。

**验证设置生效：**

- [ ] 随便找一个 `.txt` 文件，如果文件名后能看到 `.txt` 后缀，说明设置成功

### 1.4.2 常见扩展名速查

| 扩展名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `.txt` | 纯文本 | 任何编辑器都能打开 |
| `.md` | Markdown | 轻量标记语言，写笔记首选 |
| `.docx` | Word 文档 | 实验报告常用 |
| `.pdf` | PDF | 课件、论文、电子书 |
| `.py` | Python 源代码 | Python 程序 |
| `.cpp` / `.h` | C++ 源代码 | 算法竞赛、课程实验常用 |
| `.zip` / `.7z` | 压缩包 | 传输多个文件时打包 |
| `.exe` | 可执行程序 | 双击运行，来源不明的不要乱开 |

## 五、文件查找与搜索

### 1.5.1 资源管理器搜索

在资源管理器右上角的搜索框输入关键词，可以在当前文件夹及其子文件夹中查找。支持的搜索语法：

| 语法 | 作用 | 示例 |
| :--- | :--- | :--- |
| `关键词` | 按文件名搜索 | `实验` |
| `ext:.扩展名` | 按扩展名过滤 | `ext:.pdf` |
| `datemodified:日期` | 按修改时间过滤 | `datemodified:今天` |
| `size:>大小` | 按文件大小过滤 | `size:>50MB` |

> [!NOTE] 搜索范围
> 资源管理器搜索只覆盖当前文件夹及其子文件夹。要全盘搜索，需要先进入"此电脑"或在 Everything 中搜索。

### 1.5.2 Everything：全盘秒搜工具

Windows 自带的搜索速度较慢，推荐安装免费工具 [Everything](https://www.voidtools.com/zh-cn/)。它能瞬间扫描全盘文件，输入关键词立刻显示结果。

#### 方法一：关键词搜索

```text
输入 "实验报告 pdf"   # 立刻列出所有名字含 "实验报告" 的 PDF 文件
```

#### 方法二：路径限定搜索

```text
输入 "D:\Projects\ *.cpp"   # 列出该项目目录下所有 C++ 文件
```

**验证 Everything 已安装：**

```powershell
where Everything   # 若返回路径，说明已加入 PATH
```

> [!TIP] Everything 是效率神器
> 装上 Everything 后，你几乎不需要再用资源管理器层层翻文件夹。按 `Win + S` 唤起搜索框，输入文件名片段，一秒定位。这是 [1.4 常用工具](/zh/docs/ch1/1.4-Common-Tools) 中最值得优先安装的工具之一。

## 六、压缩与解压

### 1.6.1 何时需要压缩

| 场景 | 作用 |
| :--- | :--- |
| 传输多个文件 | 把一整个文件夹打包成一个文件，方便发送 |
| 减小体积 | 压缩后通常能减小 30% 到 70% 的体积 |
| 备份归档 | 把不常用的资料压缩后存档，节省空间 |

### 1.6.2 常见压缩格式

| 格式 | 特点 | 推荐场景 |
| :--- | :--- | :--- |
| `.zip` | 兼容性最好，Windows 自带支持 | 交作业、传资料 |
| `.7z` | 压缩率高，需要安装 7-Zip | 大文件备份 |
| `.rar` | 较常见，需要 WinRAR | 解压别人发的包 |

### 1.6.3 安装 7-Zip

建议安装 [7-Zip](https://www.7-zip.org/)，免费、开源、无广告，能解压几乎所有常见格式。

**操作步骤：**

1. 访问 [7-zip.org](https://www.7-zip.org/) 下载对应版本（64 位系统选 `.exe` 64-bit）
2. 双击安装包，按提示完成安装
3. 右键任意文件 → 看到 `7-Zip` 菜单项即安装成功

**验证安装：**

- [ ] 右键一个文件，如果菜单中出现 `7-Zip` 选项，说明安装成功

> [!TIP] 压缩与解压操作
>
> - **压缩**：右键文件 → `7-Zip` → `添加到压缩包` → 选择格式（建议 `.zip` 兼容性最好）
> - **解压**：右键压缩包 → `7-Zip` → `提取到当前位置`，或双击压缩包打开后拖出文件

> [!IMPORTANT] 解压前先看内容
> 解压前先双击打开压缩包，确认里面的文件是你期望的，避免解压出大量乱七八糟的文件污染当前目录。尤其是不明来源的压缩包，可能含恶意脚本。
