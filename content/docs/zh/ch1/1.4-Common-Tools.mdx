## 一、软件获取与安装

一款软件从安装到卸载，大致会经历这样一个生命周期：

```mermaid
flowchart LR
    A[获取<br/>官网 / 应用商店] --> B[安装<br/>自定义选项]
    B --> C[使用<br/>按需启动]
    C --> D[更新 / 卸载<br/>系统卸载或使用 Geek Uninstaller 等工具]
```

### 1.1 获取渠道

| 渠道 | 说明 | 适用 |
| :--- | :--- | :--- |
| 官网 | 软件官方站点，文件完整、来源可信 | 几乎所有软件 |
| 系统应用商店 | 微软商店，自动更新、隔离运行 | 商店上架的软件 |
| 第三方下载站 | 常捆绑“高速下载器”与全家桶 | 不推荐 |

> [!CAUTION] 警惕“下载器”与捆绑安装
> 部分第三方下载站的“高速下载”按钮其实是流氓下载器，会静默安装流氓软件全家桶。
>
> 下载软件请认准官网，安装时勾选“自定义安装”，安装到数据盘（如 `D:`），并取消附加软件勾选。

### 1.2 安装与卸载

- **安装**：大型软件装到数据盘（如 `D:`），避免系统盘膨胀；随时取消勾选捆绑选项。
- **卸载**：`设置` → `应用` → `已安装的应用` 中找到后卸载，切勿直接删除安装文件夹，更不要以为删掉快捷方式就是卸载。
- **残留清理**：推荐 [Geek Uninstaller](https://www.geekuninstaller.com/)，免费绿色，卸载后能顺手清理注册表与残留目录。

> [!TIP] 卸载后检查残留
> 卸载后可以用 [1.1 文件管理](/zh/docs/ch1/1.1-File-Management#113-路径绝对路径与相对路径) 学到的路径知识，到 `%APPDATA%`、`%LOCALAPPDATA%` 与 `Program Files` 下检查是否残留目录。

> [!NOTE] 更多安装注意事项
> 安装路径选择、启动项管理、破解版风险等更多细节，见 [1.2 Windows 设置](/zh/docs/ch1/1.2-Windows-Settings#五应用管理) 中的“应用管理”（含安装注意事项与安全提醒）部分。

## 二、输入与文字工具

### 2.1 输入法

| 输入法 | 特点 |
| :--- | :--- |
| 微软拼音 | 系统自带，无广告、隐私好，日常够用 |
| 搜狗 / 微信输入法 | 词库与功能更丰富，但注意推广弹窗与隐私条款 |

> [!IMPORTANT] 输入法能看到我们输入的所有内容
> 输入法默认联网使用云词库与同步功能，理论上能记录我们的输入内容。敏感场合建议关闭云同步，或切换到系统自带输入法。

### 2.2 文本编辑

- **记事本**：Windows 11 自带多标签与未保存提示，日常随手记录够用。
- [Notepad3](https://github.com/rizonesoft/Notepad3)：开源轻量，语法高亮，适合快速查看与修改文本。
- [Notepad--](https://github.com/cxasm/notepad--)：国产开源、跨平台（Windows/Linux/macOS）的文本编辑器，支持多标签等，是 Notepad++ 的替代品之一。
- **VS Code**：免费开源的代码编辑器，是后续开发的主力，安装步骤见 [1.7 文本编辑](/zh/docs/ch1/1.7-Text-Editing)，环境配置见 [1.14 环境配置](/zh/docs/ch1/1.14-Environment-Setup)。

### 2.3 PDF 阅读

- **Edge 浏览器的内置 PDF 阅读器**：无需额外安装，打开即读。
- **Acrobat Reader**：Adobe 官方免费 PDF 阅读器，功能完整，支持批注、签名与表单填写。
- **WPS PDF**：支持批注、签名、PDF 转换等功能，界面简洁，集成在 WPS Office 中（部分功能需会员）。

## 四、截图与屏幕录制

### 4.1 系统自带截图

| 方式 | 操作 | 特点 |
| :--- | :--- | :--- |
| 快捷键 `Win + Shift + S` | 调出截图栏 | 截图自动复制到剪贴板，可直接粘贴 |
| `PrtSc` 键 | 截全屏 | 复制到剪贴板 |
| `Alt + PrtSc` | 截当前活动窗口 | 复制到剪贴板 |

> [!TIP] 最常用的截图方式
> `Win + Shift + S` 最常用，截图后直接在聊天软件或编辑器里 `Ctrl + V` 粘贴，无需先存成文件。

### 4.2 推荐工具：PixPin

[PixPin](https://pixpin.cn/) 是国产截图工具，绝大部分功能免费、无需注册即可使用。
在截图与贴图之外，还集成了长截图、动图录制、屏幕录制与 OCR 文字识别等功能，对写文档、对比参考图有很大帮助。

> [!DETAILS-HINT] 贴图功能怎么用
> 按 `Ctrl + 1` 框选截图，再按 `Ctrl + 2`，截图就会被“钉”在屏幕上，可随意拖动、缩放。
>
> `Esc` 可退出截图选区。写文档时对照参考非常方便。

### 4.3 剪贴板历史

按 `Win + V` 打开剪贴板历史，可以粘贴历史复制过的内容；点击 `📌` 按钮可固定常用条目。

> [!NOTE] 剪贴板历史与跨设备同步
> 剪贴板历史默认仅保存在本机；若在设置中开启“跨设备同步”，内容会通过微软账户同步到其他设备。
> 敏感信息复制时需保持谨慎，并记得在设置中清除历史记录。

### 4.4 屏幕录制

- [OBS Studio](https://obsproject.com/)（推荐）：免费开源，功能完善，支持多平台录制。
- `Win + G`（Xbox Game Bar）：系统自带录屏，适合录制窗口与操作演示。
- PixPin：支持动图（GIF/WebP）与视频（MP4）录制，适合生成教程动图、录制操作演示与报错复现记录。

## 八、值得我们思考的问题

> [!DETAILS-FAQ] 为什么 `Everything` 能“瞬间”搜到全盘文件，而 Windows 自带搜索却要等很久？
> 关键在于两者检索的对象完全不同。
>
> - `Everything` 直接读取 NTFS 文件系统的 **MFT（主文件表）**，并借助 **USN 变更日志** 实时增量更新，只检索文件名与元数据，不检索文件内容，因此速度极快；
> - Windows 搜索默认建立全文本索引（会分析文件内容），索引范围与更新时机受策略影响，首次搜索大量文件时往往需要“现场扫描”。
>
> 这告诉我们：工具“快”通常不是魔法，而是**换了一种更精准的检索对象**。需要按内容搜索时，Windows 搜索或全文索引类工具才更合适。

> [!DETAILS-FAQ] 直接删除软件的安装文件夹，为什么不算“卸载”？
> 软件安装时写入的信息远不止文件本身，还包括：
>
> - 注册表：安装信息、卸载入口、开机启动项、右键菜单、文件关联；
> - 系统服务与开机自启项；
> - 环境变量（如 `PATH`）。
>
> 只删文件夹，这些“痕迹”仍然存在：启动项照常运行、右键菜单残留、`已安装的应用` 中仍显示该软件。这正是 [Geek Uninstaller](https://www.geekuninstaller.com/) 等工具的价值——先执行官方卸载程序，再扫描清理残留的注册表项与目录。

> [!DETAILS-FAQ] 输入法为什么要联网？“云词库”到底上传了什么？
> 输入法联网主要服务于三类功能：**云词库 / 云候选**（结合热门输入给出联想）、**词库与配置同步**（多设备一致）、**更新与推广**。
>
> 这些功能在工作时需要把当前输入的内容（或经过处理的拼音串）发送到服务器以换取候选词，因此**理论上存在输入内容被记录的风险**。敏感场合（账号密码、论文、工作机密）建议：关闭云同步与联网词库、改用纯本地模式的输入法，或切换到系统自带输入法——这也是本节 `IMPORTANT` 提示想强调的：**免费工具的“云”功能，本质上是一种数据交换**。

> [!DETAILS-FAQ] 剪贴板里的内容，真的只属于我们自己吗？
> 剪贴板是**系统级的全局共享区域**，任何前台运行的程序都可以读取，历史上也出现过专门监视剪贴板的恶意软件（俗称“剪贴板劫持”，例如悄悄替换复制的钱包地址）。Windows 的剪贴板历史在本机以加密形式存储，但若开启了“跨设备同步”，内容会经微软账户在设备间传输。
>
> 因此：复制过密码、卡号等敏感信息后，及时用无关内容覆盖；不在公共电脑上开启剪贴板同步。和输入法一样——**凡是我们复制过的，都可能成为软件的数据**。
