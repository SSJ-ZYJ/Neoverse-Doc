## 一、打开设置的方式

| 方式 | 操作 | 说明 |
| :--- | :--- | :--- |
| 快捷键 | `Win + I` | 最推荐，任何时候都能秒开 |
| 开始菜单 | 点击 `开始` → 齿轮图标 | 适合鼠标操作 |
| 搜索 | 按 `Win` 键，输入"设置" | 快捷方便 |
| 命令 | 终端运行 `start ms-settings:` | 脚本场景使用 |

## 二、显示与个性化

### 1. 分辨率与缩放

设置路径：`设置` → `系统` → `屏幕`

| 项目 | 建议值 | 说明 |
| :--- | :--- | :--- |
| 分辨率 | 带"(推荐)"字样的选项 | 通常是显示器的原生分辨率 |
| 缩放 | 1080P 一般选 100%，2K 及以上选 125% 或 150% | 根据屏幕尺寸调整 |

**验证设置：**

- [ ] 打开一个文本文件，文字清晰无锯齿、窗口不被裁切，说明分辨率和缩放合适

### 2. 深色模式

长时间盯屏幕容易视疲劳，深色模式能减轻一些不适。

设置路径：`设置` → `个性化` → `颜色` → `选择模式` → `深色`

> [!TIP] 编程建议用深色模式
> 对编程而言，深色模式几乎是默认选择，多数编辑器和终端主题也是深色优先。如果你白天晚上想自动切换，可选 `自定义`，分别设置白天和晚上的模式。

### 3. 桌面图标

默认情况下 Windows 11 桌面只有回收站，想显示"此电脑"等图标：

右键桌面 → `个性化` → `主题` → `桌面图标设置` → 勾选需要的图标。

## 三、电源与睡眠

### 1. 设置睡眠时间

| 场景 | 屏幕关闭 | 进入睡眠 |
| :--- | :--- | :--- |
| 接电源 | 10 分钟 | 30 分钟 |
| 用电池（笔记本） | 5 分钟 | 15 分钟 |

设置路径：`设置` → `系统` → `电源和电池`（Windows 10 为 `电源和睡眠`）。

### 2. 合盖行为（笔记本）

笔记本合盖时默认会睡眠，但如果你在下载大文件或跑长时间任务，可以临时改为"不做任何操作"：

设置路径：`控制面板` → `硬件和声音` → `电源选项` → `选择关闭盖子的功能`

> [!WARNING] 合盖不睡眠的风险
> 合盖不睡眠会让笔记本在包里持续发热，严重时可能损坏硬件。长时间携带务必改回"睡眠"。

## 四、存储管理

### 1. 查看磁盘占用

设置路径：`设置` → `系统` → `存储`

这里能看到每个盘符的已用空间和剩余空间，点进去还能看到"应用""临时文件""文档"各自占了多少。发现 C 盘快满时，先来这里排查是谁在占地方。

### 2. 更改默认保存位置

新电脑在安装软件时，可在 D 盘创建 `D:\Program Files` 文件夹作为默认安装路径。可右键左侧 `桌面`、`文档`、`下载` 等文件夹，依次点击 `属性` → `位置` → `移动`，将它们改到 D 盘。

### 3. 存储感知：自动清理

开启"存储感知"后，Windows 会自动清理临时文件和回收站里超过 30 天的内容，不用自己手动清理。

设置路径：`设置` → `系统` → `存储` → 开启 `存储感知`

**验证存储感知已开启：**

- [ ] 回到 `存储` 页面，看到 `存储感知` 开关为"开"状态即生效

### 4. 磁盘清理

想手动释放空间，可以用系统自带的"磁盘清理"工具：

在开始菜单搜索"磁盘清理" → 选择要清理的盘符 → 勾选要删除的文件类型。

## 五、应用管理

### 1. 安装与卸载

| 操作 | 路径 |
| :--- | :--- |
| 查看已装应用 | `设置` → `应用` → `已安装的应用` |
| 卸载应用 | 找到应用 → 点击右侧 `…` → `卸载` |
| 修改默认应用 | `设置` → `应用` → `默认应用` |

> [!IMPORTANT] 卸载软件的正确方式
> 直接删快捷方式是没用的，必须通过"已安装的应用"卸载，否则注册表和残留文件会越积越多，最终拖慢系统。

### 2. 启动项管理

电脑开机越来越慢？很可能是开机自启的软件太多了。

设置路径：`设置` → `应用` → `启动` → 把不需要开机启动的应用关掉。

任务管理器也能管理启动项：`Ctrl + Shift + Esc` 打开任务管理器 → 切换到 `启动应用` 标签页（Windows 10）或左侧 `启动` 图标（Windows 11）。

### 3. 安装软件的注意事项

| 注意点 | 说明 |
| :--- | :--- |
| 去官网下载 | 不要在第三方下载站下载，它们通常捆绑流氓软件 |
| 选自定义安装 | 取消勾选"推荐安装的附加软件" |
| 注意安装路径 | 大型软件可以装到 `D:` 盘，避免 C 盘膨胀 |
| 警惕 `.exe` 来源 | 来源不明的可执行文件可能含病毒 |

> [!CAUTION] 安全提醒
> 详见 [1.4 常用工具](/zh/docs/ch1/1.4-Common-Tools) 中的安全习惯部分。下载破解版软件是中木马、勒索病毒的主要途径，请用开源替代品或申请学生免费授权。

## 六、账户与登录

### 1. 微软账户 vs 本地账户

| 类型 | 优点 | 缺点 |
| :--- | :--- | :--- |
| 微软账户 | OneDrive 同步、跨设备设置同步、应用商店 | 需要联网登录，隐私顾虑 |
| 本地账户 | 无需联网，隐私性好 | 失去同步功能 |

建议日常用微软账户，方便 OneDrive 备份；如果注重隐私，可在 `设置` → `账户` → `你的信息` 中改为本地账户登录。

### 2. 设置 PIN 或指纹

密码太长每次输入麻烦，建议设置 PIN 或指纹（支持的话）：`设置` → `账户` → `登录选项`。

> [!INFO] PIN 比密码更安全
> PIN 只在本机有效，即使泄露也无法在别的设备上登录你的账户，比密码更安全。配合 Windows Hello 指纹识别，体验更佳。

## 七、环境变量

### 1. 什么是环境变量

环境变量是系统级别的配置值，最常见的用途是让系统知道某个程序在哪里。比如你安装了 Python，但在终端输入 `python` 却提示"不是内部或外部命令"，往往就是因为 Python 的路径没加到环境变量 `PATH` 里。

### 2. 查看与修改

| 操作 | 方法 |
| :--- | :--- |
| 临时查看 | 终端运行 `echo %PATH%`（CMD）或 `$env:PATH`（PowerShell） |
| 永久修改 | `Win + R` → 输入 `sysdm.cpl` → `高级` → `环境变量` |

> [!NOTE] 两种环境变量
> 环境变量分"用户变量"和"系统变量"。用户变量只对当前用户生效，系统变量对所有用户生效。一般配置自己的开发工具，加到"用户变量"即可，避免动系统变量影响其他用户。

### 3. PATH 变量详解

`PATH` 是最重要的环境变量，它是一串用分号分隔的目录路径。当你在终端输入一个命令（如 `python`），系统会依次在这些目录里找对应的可执行文件，找到就执行，找不到就报错。

**添加新程序到 PATH 的步骤：**

1. 找到程序可执行文件所在目录，例如 `D:\Python\Python312`
2. 打开环境变量设置，在"用户变量"里找到 `Path`
3. 点击 `编辑` → `新建` → 粘贴目录路径 → `确定`
4. **重新打开**终端（修改后旧终端窗口不生效）

**验证 PATH 配置：**

```powershell
python --version   # 若输出 Python 版本号，说明 PATH 配置成功
```

> [!TIP] 安装时勾选 Add to PATH
> 很多软件安装时勾选"Add to PATH"就会自动帮你配好，不用手动设置。如果忘了勾选，再按上面的步骤补上即可。

### 4. 如何判断处理器架构

配置环境变量或下载软件时，常需要判断系统是 64 位还是 32 位、是 x64 还是 ARM：

| 方法 | 操作 | 输出示例 |
| :--- | :--- | :--- |
| 设置查看 | `设置` → `系统` → `系统信息` → `系统类型` | `64 位操作系统, x64 处理器` |
| 命令查看 | 终端运行 `echo %PROCESSOR_ARCHITECTURE%` | `AMD64`（即 x64） |

> [!IMPORTANT] 下载软件前先确认架构
> 下载 Git、Node.js、Python 等工具时，要选择对应架构的安装包。现在绝大多数 Windows 电脑是 `x64`（AMD64），苹果 Silicon 设备运行 Windows 时是 `ARM64`。装错架构会直接报错无法运行。

## 八、终端与命令行

### 1. 打开终端的方式

| 方式 | 说明 |
| :--- | :--- |
| `Win + R` → 输入 `cmd` | 打开传统 CMD |
| `Win + R` → 输入 `powershell` | 打开 PowerShell |
| 右键文件夹空白处 → `在终端中打开` | Windows 11 自带，直接定位到当前目录 |
| 开始菜单搜索"终端" | 打开 Windows Terminal（推荐） |

### 2. 常用命令速查

| 命令 | 作用 | 示例 |
| :--- | :--- | :--- |
| `cd 路径` | 切换到指定目录 | `cd D:\Projects` |
| `dir` | 列出当前目录文件 | `dir` |
| `mkdir 名字` | 创建文件夹 | `mkdir notes` |
| `del 文件` | 删除文件 | `del old.txt` |
| `cls` | 清空屏幕 | `cls` |
| `where 命令` | 查找命令所在位置 | `where python` |

> [!INFO] 命令行的深入学习
> 这里只列了最基本的命令，更深入的命令行使用（管道、重定向、权限、脚本等）见后续 Shell 章节。日常操作先用这几个够用，文件管理相关命令也可参考 [1.1 文件管理](/zh/docs/ch1/1.1-File-Management)。

### 3. 推荐安装 Windows Terminal

Windows 11 自带 Windows Terminal，Windows 10 需要从应用商店免费安装。它支持多标签页、自定义主题、GPU 加速，比 CMD 和传统 PowerShell 好用得多。

**验证 Windows Terminal 是否已安装：**

- [ ] 按 `Win` 键搜索"终端"，如果出现"终端"应用即已安装；若只搜到"命令提示符"和"Windows PowerShell"，建议去应用商店安装 Windows Terminal

## 九、Windows 更新

### 1. 为什么要更新

系统更新不只是加新功能，更重要的是修补安全漏洞。勒索病毒、木马往往利用的是早已被修补的旧漏洞，只是因为用户没及时更新才得逞。

### 2. 更新设置

设置路径：`设置` → `Windows 更新`

| 操作 | 建议 |
| :--- | :--- |
| 自动更新 | 开启，保持系统最新 |
| 活跃时间 | 设置你常用电脑的时段，避免更新此时段内强制重启 |
| 重要节点前 | 考试或答辩前提前手动检查更新并完成重启 |

> [!WARNING] 别在关键时刻被更新打断
> 重要考试或答辩前，务必提前手动检查更新并完成重启，避免关键时刻突然弹更新。答辩时系统突然重启更新，场面会非常尴尬。

**验证系统为最新：**

- [ ] `设置` → `Windows 更新` → 点击 `检查更新` → 显示"你使用的是最新版本"即说明已是最新
