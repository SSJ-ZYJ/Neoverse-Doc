## 一、打开设置

| 方式 | 操作 | 说明 |
| :--- | :--- | :--- |
| 快捷键 | `Win + I` | 最推荐，任何时候都能秒开 |
| 开始菜单 | 点击 `开始` → 齿轮图标 | 适合鼠标操作 |
| 搜索 | 按 `Win` 键，输入“设置” | 快捷方便 |
| 命令 | 终端运行 `start ms-settings:` | 脚本场景使用 |

## 二、显示与个性化

### 2.1 分辨率与缩放

设置路径：`设置` → `系统` → `屏幕`

| 项目 | 建议值 | 说明 |
| :--- | :--- | :--- |
| 分辨率 | 带“(推荐)”字样的选项 | 通常是显示器的原生分辨率 |
| 缩放 | 1080P 一般选 100%，2K 及以上选 125% 或 150% | 根据屏幕尺寸及个人习惯调整 |

### 2.2 深色模式

长时间盯屏幕容易视疲劳，深色模式能减轻一些不适。

设置路径：`设置` → `个性化` → `颜色` → `选择模式` → `深色`

> [!NOTE] 三方应用推荐：
> [Auto Dark Mode](https://github.com/AutoDarkMode/Windows-Auto-Night-Mode) 是一款可进行深度配置，根据日出日落时间自动切换深/浅色模式的应用。
>
> 有兴趣可以尝试一下。

### 2.3 桌面图标

默认情况下 Windows 桌面只有回收站，想显示“此电脑”等图标需要进行以下设置：

右键桌面 → `个性化` → `主题` → `桌面图标设置` → 勾选需要的图标 → `应用` → `确定`。

## 三、电源与睡眠

### 3.1 设置睡眠时间

| 场景 | 屏幕关闭 | 进入睡眠 |
| :--- | :--- | :--- |
| 接电源 | 10 分钟 | 30 分钟 |
| 用电池（笔记本） | 5 分钟 | 15 分钟 |

设置路径：`设置` → `系统` → `电源和电池`（Windows 10 为 `电源和睡眠`）。

### 3.2 合盖行为（笔记本）

笔记本合盖时默认会睡眠，但如果我们正在下载大文件或运行长时间任务，可以临时改为“不执行任何操作”：

设置路径：`设置` → `系统` → `电源和电池` → `盖子、电源和睡眠 按钮控件` → `盖上盖子将我的电脑` → `不执行任何操作`

> [!WARNING] 合盖不执行任何操作的风险：
> 合盖不执行任何操作会让笔记本在包里持续发热，严重时可能损坏硬件。长时间携带务必改回 **“睡眠”** 或 建议直接关机。

## 四、存储管理

### 4.1 查看磁盘占用

设置路径：`设置` → `系统` → `存储`

这里能看到每个盘符的已用空间和剩余空间，点进去还能看到“应用”“临时文件”“文档”各自占了多少。发现 C 盘快满时，先来这里排查是谁在占地方。

### 4.2 调整文件与应用的保存位置

安装应用时，优先使用安装程序或应用商店提供的位置选项，并更改到其他盘符（如 `D:` 盘）进行安装。
若确实需要迁移 `桌面`、`文档` 或 `下载` 等用户文件夹，应先完成备份，再通过文件夹 `属性` → `位置` → `移动` 操作，迁移后检查常用软件是否仍能找到原文件。

> [!CAUTION] 不要直接剪切系统目录！
> `C:\Windows`、`C:\Program Files`、`C:\Program Files (x86)` 和整个用户目录都不应直接剪切到其他盘符。此类操作可能破坏权限、更新或卸载流程。

### 4.3 存储感知：自动清理

存储感知可以清理系统盘中的临时文件与回收站内容。它默认只管理系统盘。
`下载` 文件夹和云端文件是否会被处理，取决于我们在存储感知中的具体配置，因此首次开启后应逐项检查清理周期。

设置路径：`设置` → `系统` → `存储` → `存储感知`

### 4.4 磁盘清理

想手动释放空间，可以用系统自带的“磁盘清理”工具：

在开始菜单搜索“磁盘清理” → 选择要清理的盘符 → 勾选要删除的文件类型。

## 五、应用管理

### 5.1 安装与卸载

| 操作 | 路径 |
| :--- | :--- |
| 查看已装应用 | `设置` → `应用` → `已安装的应用` |
| 卸载应用 | 找到应用 → 点击右侧 `…` → `卸载` |
| 修改默认应用 | `设置` → `应用` → `默认应用` |

> [!WARNING] 卸载软件的正确方式：
> 使用系统、软件自身或安装平台提供的卸载功能，不要直接删除安装文件夹。
>
> ***尤其不要将删除快捷方式当做已卸载该软件。***


### 5.2 启动项管理

**开机自启** 的软件过多，会严重拖慢计算机的开机速度，尤其是配置较低的机器。我们应对开机自启的软件进行管理，关闭不必要程序的自启。

设置路径：`设置` → `应用` → `启动` → 把不需要开机启动的应用关掉。

任务管理器也能管理启动项：

`Ctrl + Shift + Esc` 打开任务管理器 → 切换到 `启动应用` 标签页（Windows 10）或左侧 `启动` 图标（Windows 11）。

### 5.3 安装软件的注意事项

| 注意点 | 说明 |
| :--- | :--- |
| 去官网下载 | 不要在第三方下载站下载，它们通常捆绑流氓软件 |
| 选自定义安装 | 取消勾选“推荐安装的附加软件” |
| 注意安装路径 | 大型软件可以装到 `D:` 盘，避免 C 盘膨胀 |
| 警惕 `.exe` 来源 | 来源不明的可执行文件可能含病毒 |

> [!CAUTION] 安全提醒
> 详见 [1.4 常用工具与软件](/zh/docs/ch1/1.4-Common-Tools#一软件获取与安全安装) 中的“软件获取与安全安装”部分。
> 下载 **破解版软件** 是中病毒、植入流氓广告弹窗的主要途径，建议使用开源替代品或申请学生包免费授权。

## 六、账户与登录

### 6.1 微软账户 与 本地账户

| 类型 | 优点 | 缺点 |
| :--- | :--- | :--- |
| 微软账户 | OneDrive 同步、跨设备设置同步、应用商店 | 需要联网登录，国内网络环境不稳定，部分服务受限 |
| 本地账户 | 无需联网，隐私性好 | 失去同步功能 |

考虑到大多数用户在新机器激活系统时，就已经被强制进行微软账户登录。故在此不做建议。

若想更改，可在 `设置` → `账户` → `你的信息` 中改为本地账户登录。

### 6.2 设置 PIN 或指纹

密码太长每次输入麻烦，建议设置 PIN 或指纹（若设备支持）：`设置` → `账户` → `登录选项`。

> [!INFO] PIN 比密码更安全
> PIN 只在本机有效，即使泄露也无法在别的设备上登录我们的账户，比密码更安全。
> 若设备支持 **Windows Hello** 指纹/面部识别，可同时开启，获得更好的解锁体验😊。

## 七、环境变量

### 7.1 什么是环境变量

环境变量是系统级别的配置值，最常见的用途是让系统知道某个程序在哪里。

比如我们安装了 Python，但在终端输入 `python` 却提示“不是内部或外部命令……”，往往就是因为 Python 的路径没加到环境变量 `PATH` 中。

### 7.2 查看与修改

| 操作 | 方法 |
| :--- | :--- |
| 临时查看 | 终端运行 `echo %PATH%`（CMD）或 `$env:PATH`（PowerShell） |
| 永久修改 | `Win + R` → 输入 `sysdm.cpl` → `高级` → `环境变量` |

> [!NOTE] 两种环境变量
> 环境变量分“用户变量”和“系统变量”。用户变量只对当前用户生效，系统变量对所有用户生效。一般配置自己的开发工具，加到“用户变量”即可，避免动系统变量影响其他用户。

### 7.3 PATH 变量详解

`PATH` 是最重要的环境变量，它是一串用分号分隔的目录路径。当我们在终端输入一个命令（如 `python`），系统会依次在这些目录里找对应的可执行文件，找到就执行，找不到就报错。

**添加新程序到 PATH ：**

1. 找到程序可执行文件所在目录，例如 `D:\Python\Python314`
2. 在 Windows 搜索中输入“环境变量” → 点击 `编辑系统环境变量` → 在弹出的系统属性窗口中，点击 `环境变量` → 在系统变量里找到 `Path` 并双击打开
3. 点击 `新建` → 粘贴目录路径 → `确定`
4. **重新打开**终端（修改后旧终端窗口不生效）

> [!TIP] 安装时勾选 `Add to PATH`
> 很多软件安装时勾选 `Add to PATH` 就会自动帮我们配好，无需手动配置。
> 如果忘记勾选，再按上面的步骤补上即可。

### 7.4 如何判断处理器架构

下载软件时，常需要判断系统是 64 位还是 32 位、是 x64 还是 ARM：

| 方法 | 操作 | 输出示例 |
| :--- | :--- | :--- |
| 设置查看 | `设置` → `系统` → `系统信息` → `系统类型` | `64 位操作系统， x64 处理器` |
| 命令查看 | 终端运行 `echo %PROCESSOR_ARCHITECTURE%` | `AMD64`（即 x64） |

> [!IMPORTANT] 下载软件前先确认架构
> 下载 **如 Git、Node.js、Python** 等工具 时，要选择对应架构的安装包。
> 现在绝大多数 Windows 电脑是 `x64`（AMD64），苹果 Silicon 设备运行 Windows 时是 `ARM64`。

## 八、Windows 更新

### 8.1 为什么要更新

系统更新不只是加新功能，更重要的是修补安全漏洞。勒索病毒、木马往往利用的是早已被修补的旧漏洞。

如今，养成良好的计算机使用习惯，即使 “裸奔”（不使用三方安全防护软件，且关闭系统自身的安全功能） 中病毒的风险也已大大降低。
考虑到近一段时间 Windows 系统更新，对计算机性能、日常使用有一定的消极影响，故可选择自动下载更新，再手动安装更新，而非自动安装更新。

### 8.2 更新设置

设置路径：`设置` → `Windows 更新`

| 操作 | 建议 |
| :--- | :--- |
| 自动更新 | 可选，保持系统最新 |
| 活跃时间 | 设置我们常用电脑的时段，避免更新此时段内强制重启 |
| 重要节点前 | 有需求前提前手动检查更新并完成重启 |

## 十、值得我们思考的问题

> [!DETAILS-FAQ] 为什么不能通过直接删除快捷方式来卸载软件？
> 在 Windows 中，普通快捷方式本质上是一个扩展名为 `.lnk` 的文件。
>
> 它本身并不保存目标文件的实际内容，而是记录目标对象的位置以及启动参数等信息。

> [!DETAILS-FAQ] 为什么部分程序安装到含中文字符的目录下会报错？
> Windows 本身支持中文路径。出现报错，通常是因为程序或其依赖组件没有正确处理 Unicode 字符，导致路径在读取、传递或保存时出现乱码。
>
> 因此，安装开发工具、游戏和命令行程序时，建议优先使用纯英文路径。

> [!DETAILS-FAQ] 刚刚安装系统更新后，系统出现严重的性能下降或日用卡顿，如何卸载更新？
> 可以通过 `设置` → `Windows 更新` → `更新历史记录` → 点击底部相关设置中的 `卸载更新` 来卸载最近安装的更新。
>
> 注意：卸载更新后，系统可能会自动重启，建议在重启前保存所有修改中的文件。
