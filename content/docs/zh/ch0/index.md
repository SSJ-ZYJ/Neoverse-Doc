## 一、欢迎来到 Neoverse-Docs

Neoverse-Docs 是一份持续更新的在线学习文档。它不会要求你一开始就掌握编程，也不要求你从第一页读到最后一页：你可以按阶段系统学习，可以围绕一个目标选择路径，也可以在遇到具体问题时直接搜索。

它暂时不是一套完整的编程语言、算法或计算机理论课程，也不是一份要求你照单全装的软件推荐清单。我们正在逐步完善内容，欢迎[参与贡献](/zh/docs/about/contributing)。

## 二、目前可以学到什么

| 内容 | 当前状态 | 适合怎样使用 |
| :--- | :--- | :--- |
| Chapter 0：开始之前 | 已可阅读 | 认识项目、选择学习路径并熟悉本站 |
| [Chapter 1：缺失的一学期](/zh/docs/ch1) | 当前主线，共 7 个 Stage、17 节 | 从文件管理与日常工具出发，逐步进入 Shell、开发环境、Git 与 Docker |
| [Chapter 2：算法入门](/zh/docs/ch2) | 建设中，目前只有导读与高精度算法草稿 | 了解后续方向；阅读现有算法内容前需要具备 C++ 基础 |
| [关于与共建](/zh/docs/about) | 持续维护 | 了解项目、参与贡献，或查阅文档语法示例 |

> [!IMPORTANT] 内容状态也是内容的一部分
> 本站只把仓库中已经存在或正在形成可阅读稿件的内容视为当前内容。未来方向可能随着实际写作与反馈调整，不应被理解为已经完成的课程承诺。

## 三、怎样看待文档中的结论

本站内容主要来自作者与贡献者的学习和实践经验。涉及命令、配置、版本与工具行为时，我们会结合当前项目、官方资料和可靠来源进行核对，也会使用 AI 辅助整理与校对。

软件界面、版本和平台规则会持续变化。执行会删除文件、覆盖配置、修改权限或影响账号安全的操作前，请先确认目标、理解后果，并以工具当前版本的官方说明为准。

## 四、反馈与修正

如果你发现事实错误、失效链接、难以理解的步骤或可以改进的表达，欢迎在当前页面下方留言，或前往 [GitHub Issues](https://github.com/SSJ-ZYJ/Neoverse-Doc/issues) 提交反馈。清楚说明页面、问题位置、你看到的现象和期望结果，会让修正更快发生。
