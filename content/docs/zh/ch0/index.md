## 欢迎来到 Neoverse-Docs

这是一份面向高校计算机科班生的一份文档，其可能会包括但不限于下列内容：

- Neoverse-Docs 使用指南
- 缺失的一学期：那些我们应该知道的东西
  - Windows: How to use
    - 文件管理与系统设置
    - 程序的安装与卸载
    - 良好的计算机使用习惯
    - 实用软件与工具
  - 提问的艺术
    - 社区与相关平台
    - 如何正确的向 AI 提问
  - 文本编辑
    - Markdown 与 Mermaid
    - LaTeX
  - Shell 基础
    - Linux 基础命令
    - 终端中的文本编辑
  - 配置环境
    - 在 VS Code 中配置 C/CPP 开发环境
    - 包管理器
  - 版本控制
    - Git
    - GitHub 与 CNB
  - Docker 基础
- C/CPP 编程语言
  - 代码质量
  - 代码之外：代码风格与格式化
  - 编译之内
  - GDB 调试

## 文档内容来源

文档主要基于作者的主观使用经验与学习过程编写，涉及理论、学识类内容会参考部分认可度较高的书籍与可信度较高的互联网资源进行查验与校对，同时也会使用 AI 工具进行辅助校对。

## 反馈与支持

尽管如此，我们仍可能在无意中出现疏漏。若发现部分内容存在问题或有可改进的部分与建议，可以给该文档仓库提 [issues](https://github.com/SSJ-ZYJ/Neoverse-Doc/issues)，进行反馈。  
若你愿意为该文档贡献自己的一份力量，可前往 `Github` 为本项目提交你的 PR 进行贡献。  
详见：[贡献指南](./about/guide)
