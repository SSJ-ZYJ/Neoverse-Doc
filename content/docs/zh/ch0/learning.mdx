## 一、开始前需要准备什么

阅读 Chapter 0 和 Chapter 1 不要求编程经验。你只需要能够使用浏览器，并愿意在自己的电脑上完成一些小操作。

不同内容的起点并不相同：

- **Chapter 0**：没有技术先修，用来选择起点和熟悉本站。
- **Chapter 1**：从日常操作与工具基础开始，可以按顺序学习。
- **Chapter 2**：仍在建设；当前算法内容使用 C++ 示例，阅读前需要掌握 C++ 基本语法。

## 二、选择一种阅读方式

| 阅读方式 | 适合你在…… | 建议做法 |
| :--- | :--- | :--- |
| 顺序学习 | 刚入门，不确定自己缺少什么 | 从 [Chapter 1 导读](/zh/docs/ch1) 开始，按 Stage 学习并完成每节任务 |
| 按目标学习 | 已经有明确目标，希望补一条能力链 | 从下方选择一条精选路径，遇到陌生前置概念时再回到对应章节 |
| 问题驱动 | 正在处理一个具体问题或报错 | 先搜索关键词，阅读最相关的小节，完成验证后再补上下游知识 |

三种方式可以混合使用。顺序学习帮助你建立整体认识；精选路径减少与当前目标无关的绕行；问题驱动则让知识和真实场景建立联系。

## 四、AI：怎样读完一页

面对一篇较长的文档，可以按下面的节奏阅读：

1. **先看摘要和目标**：判断这一页是否解决当前问题。
2. **理解核心概念**：先知道命令或工具在解决什么，不急着记住所有参数。
3. **完成一个实际操作**：在自己的环境中执行、观察结果，并确认结果是否符合预期。
4. **勾选任务清单**：用可验证的完成条件记录进度，而不是把“看过”当成“学会”。
5. **留下问题**：记录环境、操作、输出和疑问，必要时再搜索或提问。

> [!NOTE] 进度保存在哪里
> 可交互任务的勾选状态保存在当前浏览器的本地存储中，并按页面区分。它不会同步到账号或其他设备；清理站点数据后，进度也可能消失。

## 五、AI：第一次 15 分钟实践

现在就完成一次最小学习闭环。不要追求一次解决所有问题，只确认自己能够找到内容、做出操作并留下结果。

- [ ] 写下一个最近遇到的具体问题，例如“怎样显示文件扩展名”或“Git 是做什么的”
- [ ] 使用本站搜索找到一篇相关文档；不熟悉操作时查看 [0.2 使用本站](./usage)
- [ ] 阅读摘要与最相关的小节，确认它是否回答了你的问题
- [ ] 在自己的电脑上完成一个不会破坏数据的小操作，并观察结果
- [ ] 记录操作、结果和仍未解决的疑问，再勾选本项

完成后，你已经走过了一次“提出问题 → 查找信息 → 实际操作 → 验证结果 → 记录疑问”的闭环。接下来可以继续当前页面，也可以回到 [Chapter 1 导读](/zh/docs/ch1) 选择下一节。
